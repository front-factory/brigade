# Audit: project alignment (goal vs mechanisms vs field practice)

Date: 2026-10-31
Baseline commit: 670bfdd
Scope: whole project (kit in `templates/web/.claude/`, `src/`, README, this repo's dogfood `.claude/`), compared with Claude Code conventions and with the hand-built setup of the sibling project hemera (ancestor of this kit).
Status: open

## Findings

| H1 | high | templates/web/.claude/settings.json, templates/web/.claude/hooks/ | `defaultMode: plan` is useful but not sufficient: it blocks edits at session start and forces thinking before acting, but once a plan is approved (ExitPlanMode) or the user presses Shift+Tab, the session leaves plan mode for default, acceptEdits or auto and never returns to it on its own, so the main session can Edit/Write for the rest of the session. Keep `defaultMode: plan` and add a PreToolUse hook on `Edit\|Write\|NotebookEdit` that denies when `agent_type` is empty (allow `CLAUDE.local.md` and `.claude/settings.local.json`, written by `/brigade-settings`): it holds the rule for the whole session; the git-guard infrastructure (`agent_type`) already exists. | deferred | Set aside by the user on 2026-10-31 (complex topic); keep defaultMode: plan as decided. |
